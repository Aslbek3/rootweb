## 1. Resurs cheklovi (eng muhimi, kodsiz)

O'lchangan holat: 26 root bot ~3.3 GB + 8 sandbox bot ~1.2 GB + tizim
~0.5 GB = **~5 GB Claude ishlamaganda**. Har ochiq Claude sessiyasi ustiga
300-400 MB. Cheklov yo'q — xotira tugasa OOM killer qurbonni o'zi tanlaydi.

### claudeuz (alohida systemd xizmati — oson)

```bash
cd /root/vps/claudeweb
git pull

sudo mkdir -p /etc/systemd/system/pm2-claudeweb.service.d
sudo cp deploy/systemd-limits-sandbox.conf /etc/systemd/system/pm2-claudeweb.service.d/limits.conf

sudo systemctl daemon-reload
sudo systemctl restart pm2-claudeweb
systemctl show pm2-claudeweb -p MemoryMax -p CPUQuota -p TasksMax
```

### rootweb

rootweb root'ning **umumiy** PM2 daemonida ishlaydi, ya'ni bu cheklov
26 ta botga ham tegadi. Bu VPS uchun himoya — OOM butun tizim bo'ylab
emas, shu cgroup ichida ishlaydi.

```bash
sudo mkdir -p /etc/systemd/system/pm2-root.service.d
sudo cp /root/vps/rootweb/deploy/systemd-limits-root.conf /etc/systemd/system/pm2-root.service.d/limits.conf
sudo systemctl daemon-reload
sudo systemctl restart pm2-root
```

### Botlarga xotira chegarasi

```bash
# Ko'p botlar 130-150 MB; eng kattalari 220-270 MB
pm2 restart zayafka-bot --max-memory-restart 400M
pm2 restart postyubor-bot --max-memory-restart 400M
# qolganlariga 300M
pm2 save
```

## 2. rootweb — kod

```bash
cd /root/vps/rootweb
git status                  # lokal o'zgarish bo'lsa: git stash push -u
cp .env .env.bak_$(date +%Y%m%d_%H%M)

git fetch origin && git log --oneline HEAD..origin/main
git merge origin/main

npm install --no-audit --no-fund
npm test                    # 17 ta test o'tishi SHART, yiqilsa to'xtang
```

`.env` ga yangi qatorlarni qo'shing:

```
INSTANCE_MODE=root
MAX_SESSIONS=3
SESSION_IDLE_MINUTES=45
PROXY_PORT=0
```

```bash
pm2 restart rootweb --update-env
pm2 logs rootweb --lines 30 --nostream --err
```

Tekshirish:

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://rootweb.duckdns.org/login.html
# login qilib: holat tabi ochiladimi, botlar panelida 💬 tugma bormi
```

## 3. claudeuz — kod

⚠️ Bu deploy **katta**: 44 fayl, 20+ xavfsizlik tuzatishi. Fayllar
`claudeweb` foydalanuvchisiga tegishli bo'lishi kerak.

```bash
cd /root/vps/claudeweb
git status
cp .env .env.bak_$(date +%Y%m%d_%H%M)

git fetch origin && git merge origin/main
npm install --no-audit --no-fund
npm test                    # 17 ta test

# root sifatida tahrirlangan bo'lsa egalikni tiklang
chown -R claudeweb:claudeweb /root/vps/claudeweb
```

`.env` ga qo'shing:

```
INSTANCE_MODE=sandbox
PUBLIC_ORIGIN=https://claudeuz.duckdns.org
MAX_SESSIONS=2
SESSION_IDLE_MINUTES=45
PROXY_PORT=3212
PROXY_PREFIX=/savdo
```

```bash
sudo -u claudeweb -H bash -lc '/usr/local/bin/pm2 restart claude-code-web --update-env'
sudo -u claudeweb -H bash -lc '/usr/local/bin/pm2 logs claude-code-web --lines 30 --nostream'
```

Tekshirish:

```bash
curl -s -o /dev/null -w '%{http_code}\n' https://claudeuz.duckdns.org/login.html
curl -s -o /dev/null -w '%{http_code}\n' https://claudeuz.duckdns.org/savdo/   # proksi ishlayaptimi
```

## Deploy'dan keyin nima o'zgaradi

1. **Barcha sessiyalar tugaydi** — token formati o'zgardi, qaytadan login.
2. **claudeuz'da standart rejim "manual"** — har amal tasdiq so'raydi.
   Bu ataylab: u yerda mijozlarga xizmat qiladigan bot kodi turadi.
3. **Ba'zi buyruqlar tasdiq so'raydi** (`docker`, `psql`, `chmod`,
   `python3 -`, `curl -F`). Kundalik buyruq keraksiz so'rasa:
   `server/bashPolicy.js` → `ALLOWLIST` ga qo'shing va testga qator yozing.
4. **Claude o'zbekcha gapiradi va ish davomida izohlaydi** — faqat yangi
   sessiyalarda. Mavjud suhbatda ko'rish uchun "chatni tozalash".
5. **💬 bot suhbati** — botlar panelida. Bosilganda o'sha botning
   papkasida toza suhbat ochiladi.
